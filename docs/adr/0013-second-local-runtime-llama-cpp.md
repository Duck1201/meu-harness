# Segundo runtime local: llama.cpp, para os Challengers que o Ollama não serve

O perfil funcional chegou ao teto do que um Qwen3.5-4B abliterated entrega, e as limitações residuais da primeira release terminam todas em "sai do rol com um RuntimeProfile que...". Metade dos candidatos que valem medir não roda direito no Ollama: GGUF puxado do Hugging Face não ganha o renderer e o parser da família (issue #17636 do Ollama), então o tool calling do Agents-A1-4B depende de um Modelfile montado à mão; o CoVe-4B fala o formato Hermes; e o fine-tune de tool calling do Gemma 4 E4B nem tem tools no template que o Ollama aplicaria. O `llama-server` do llama.cpp aplica o template jinja embutido no próprio GGUF e devolve as tool calls já separadas numa API compatível com OpenAI, e é esse o segundo runtime: `LlamaCppRuntime` implementa a mesma porta `ModelRuntime`, `runtime.backend` no perfil escolhe entre os dois, e o embedding continua no Ollama, porque o acervo foi indexado pelo `bge-m3` de lá e um bake-off compara modelos de chat diante das mesmas passagens.

A identidade do modelo muda de natureza. No Ollama ela é a tag e o digest do manifesto; no llama.cpp o servidor carrega um arquivo, então o que prova o perfil é o SHA-256 do GGUF que `/props` diz estar carregado, conferido antes do primeiro Turn junto da janela (`n_ctx` igual ao `num_ctx` do perfil). O arquivo é do host, declarado em `host.json#gguf_paths`, e o digest é do contrato, em `installation.gguf_sha256`; um servidor com outro arquivo deixa o harness sem runtime, nunca com o modelo errado. Em produção o harness não sobe o servidor — `scripts/llama-server.sh` monta a linha de comando a partir das duas fontes — e na bancada o `LlamaCppLauncher` sobe e derruba um por braço, numa porta própria, porque dois modelos de chat não cabem juntos numa placa de 8 GB.

O que isto não decide é qual modelo vence. Um perfil llama.cpp entra como Challenger e só vira o perfil funcional pelo protocolo de promoção, com o mesmo corpus e os mesmos gates do Ollama; o runtime ser outro não é mérito nem demérito medido.
